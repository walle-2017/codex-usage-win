# Embedded UI fonts

These font assets are bundled into the executable and registered privately for the current process only.

- Inter Variable: primary application/taskbar/menu/settings UI font.
- Noto Sans SC UI subset: Simplified Chinese UI font. Generated from the project's actual non-ASCII UI glyphs.
- JetBrains Mono: JSON editor and monospaced configuration text.

The Noto Sans SC file is generated by `scripts/prepare-font-assets.py` from the official variable font at weight 400. It is intentionally subsetted to keep the portable executable small.

Licenses are stored in `assets/fonts/licenses/`.
